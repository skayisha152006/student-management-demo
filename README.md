
# Student Management System using DevOps

## 1. Project Overview
This project is a simple Python-based Student Management System.
It allows users to add, view, search, and delete student records.

## 2. Tools Used
- Python
- VS Code
- Git
- GitHub
- GitHub Actions
- Docker
- unittest

## 3. Implementation
1. Developed the Student Management application using Python.
2. Created five automated test cases using unittest.
3. Uploaded the source code to GitHub using Git.
4. Configured GitHub Actions for automatic testing.
5. Created a Dockerfile.
6. Built and executed the Docker container.

## 4. Testing Results
All five test cases passed successfully.

## 5. Challenges Faced
- Understanding Git commands.
- Configuring GitHub Actions.
- Creating the Docker image.
- Running the application inside Docker.

## 6. Conclusion
The project successfully demonstrates Python application
development and DevOps practices through Git, GitHub,
automated testing, GitHub Actions, and Docker.
